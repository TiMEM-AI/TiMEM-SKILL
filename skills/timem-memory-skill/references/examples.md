# 会话保存示例

| 用户的回复 | 下一步 | 写入次数 |
| --- | --- | --- |
| “不存”或未回复 | 继续当前任务 | 0 |
| “帮我记一下” | 追问存到哪个项目，等待回复 | 0 |
| “查询项目 A 的记忆” | 只读项目 A | 0 |
| “把这段存到项目 A” | 在个人连接解析唯一的 A，核对范围后提交本次内容 | 1 |
| “存到项目 A”，但有两个同名项目 | 展示候选并等待选择 | 0 |
| “存到未归类” | 核对个人未归类作用域，按该范围保存 | 1 |
| 上次同意过，或目录里已绑定 A | 重新询问本次意愿和目标 | 0 |
